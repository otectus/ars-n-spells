# Iron's glyph coverage

<!-- Hand-written text above the marker is kept by the generator. -->

One row per spell registered by **Iron's Spells 'n Spellbooks 1.21.1-3.16.3**, the pinned base catalog. The table is generated from the inventory dumped by a development runtime, and the machine-readable copy is `iron-glyph-coverage.json`:

```
./gradlew runGameTestServer -PwithIronsRuntimeGameTests -PglyphCatalogDump=<inventory.json>
python3 -I tools/generate_iron_glyph_catalog.py <inventory.json>
```

The generator also writes the shipped catalog (`src/main/resources/ans_glyph_catalog/irons_spellbooks.json`) and the glyph names. `IronGlyphCatalogGameTests#ironsLoaded_inventoryDumpAndCatalogCoverage` checks the shipped catalog against the loaded registry on every Iron's-loaded run, so a spell added to the pinned registry cannot be left out.

**Coverage.** 111 ordinary player spells are supported, with one glyph per level: 777 glyphs. Nothing is excluded except:

- `irons_spellbooks:none`, Iron's empty-slot placeholder;
- ANS's own `ars_n_spells:ars_cross_*` proxies, which import nothing;
- `soulfire_ray` and `thunder_step`, which exist as classes in the jar but are not registered by 3.16.3, so no scroll can hold them.

**Columns.**

- **adapter**: one of the built-in adapters in `adapter-authoring.md`.
- **supported forms**: the forms the spell book editor accepts for the spell's target.
- **augments**: the augments the glyph advertises, each with a tested effect.
- **prerequisites**: Iron's learning (Eldritch) or Iron's default config.
- **status/reason**: what the glyph does.
- **test evidence**: two names per row. The first is the representative family test in `ImportedGlyphGameTests`, which proves that family's world effect. The second is the generated per-spell scenario in `ImportedGlyphSmokeGameTests` (`glyph_smoke_<spell>`, at the spell's lowest level), which must record the effect as applied, or a channel as completed, for that exact spell. Each adapter family also runs one spell at its highest level (`glyph_smoke_max_<adapter>`).

**Exceptions, each tested for what can run.**

- `cloud_of_regeneration` is disabled by Iron's default config. Its scenario requires the glyph to be dormant for exactly that reason.
- `pocket_dimension` needs Iron's pocket-dimension level, which the GameTest server does not create. Its scenario requires the native failure to be caught and reported, with no crash and no charge.
- `sacrifice` targets the caster's own summon, which Iron's finds by owner UUID. GameTest fake players cannot be found that way. Its scenario requires Iron's own target filter to refuse.

The successful paths of `pocket_dimension` and `sacrifice` remain manual checks.
