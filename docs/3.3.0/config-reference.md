## `Mana Unification.cross_system_regen_conversion`

Default: `"EQUAL_EFFECT"`. Declaration arguments after default: `none`.

How mana regen values are translated when crossing the Ars / Iron's boundary. Iron's regen is a percentage-of-pool multiplier; Ars regen is absolute mana/sec. Without conversion, an Ars enchantment like Mana Regen III applied to Iron's regen will produce hundreds of mana/sec because the absolute value is misread as a percentage.   EQUAL_EFFECT  - Convert by the target system's current max pool (DEFAULT, recommended).                   Preserves equivalent mana/sec on both sides at any pool size. DISABLED      - Do not translate cross-system regen at all. Mana Regen enchantments                   on Ars only affect Ars; Iron's gear regen only affects Iron's.
